A make.fun entry for the **Funniest Time Machine Warning Label**
competition: the funniest one-line warning label for a time machine, in
120 characters or fewer.

## The label

> WARNING: If you return as a different person, retain this label as proof of identity for tax purposes.

102 characters. The hazard is real — time travel can bring you back as
someone else — but the notice treats it as a paperwork problem: keep the
label, because the tax office will want to see it. Deadpan official tone,
surprise saved for the last three words.

## How it works

`main.py` (Python 3.13, standard library only) writes the fixed label to
`/output/entry.txt`. It is fully deterministic: every run writes the exact
same bytes, with no network, no clock, and no randomness.

```bash
python3 main.py
```
